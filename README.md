# 💪 FitZone | Modern Fitness Website

A modern, responsive, bilingual fitness website built with HTML, CSS, and JavaScript.

FitZone is a fitness club website concept designed to provide a clean user experience across desktop and mobile devices.

## 🌐 Live Demo

🔗 **Website:** https://denizlashani87-dot.github.io/fitzone/

## ✨ Features

- 🌍 Bilingual interface: Persian and English
- 📱 Responsive design for desktop and mobile
- 🏋️ Workout programs and fitness sections
- 👥 Trainer profiles
- 💳 Membership plans
- 💬 Contact section and interactive elements
- 🎨 Modern dark theme with lime-green accents

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🎯 Project Goal

This project was created to practice front-end development, responsive web design, and user interface design.
